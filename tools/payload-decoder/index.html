اگر فقط `data_enc` را داری، همان را داخل JSON بگذار.

اگر payload شامل `auth` باشد، همان `auth` روی wire decode می‌شود و از مقدار دستی جلوتر است.

اگر payload شامل `tmp_session` باشد، همان مستقیما برای decode استفاده می‌شود.

اگر هیچ‌کدام نبود، مقدار فیلد `auth` و نوع انتخاب‌شده استفاده می‌شود.
